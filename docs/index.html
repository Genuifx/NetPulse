为 AI Agent 而设计

让你的 Agent 直接调用 NetPulse，拿到稳定、可解析的网络体检结果，再由它完成选购建议、故障诊断或自动巡检。

1

本地发起，批量巡检

--host 可重复指定，一次体检整个 fleet，多机自动输出对比表。

2

非交互、可脚本化

无确认、无彩色（JSON 模式），失败给清晰错误与非零退出码，agent 不会卡住。

3

远端要求透明

远端只需 python3 + requests（`pip install requests`）+ SSH key 登录，缺依赖时报错清晰，不静默改动远端环境。

# 本地发起：经 SSH 在远端执行，结果拿回本地
python3 netpulse.py --host root@1.2.3.4 --json | jq .

# 批量巡检整个 fleet
python3 netpulse.py --host root@vps-a --host root@vps-b --json \
  | jq '.[] | {host, purity, ipv6}'
import json, subprocess

def netpulse_check(host) -> dict:
    """供 Agent 调用的 VPS 网络体检：本地发起，远端执行"""
    out = subprocess.run(
        ["python3", "netpulse.py", "--host", host, "--json"],
        capture_output=True, text=True, timeout=300,
    )
    return json.loads(out.stdout)

report = netpulse_check("root@1.2.3.4")
unlocked = sum(1 for v in report["unlock"].values() if v == 200)
print(report["purity"], f"{unlocked}/11 解锁")

FAQ

常见问题

NetPulse 支持哪些系统？
有 Python 3 就行：主流 Linux 发行版和 macOS。单文件，只依赖 requests（远端需预装：`pip install requests`）。
运行一次需要多长时间？
完整体检通常 1–2 分钟，主要耗时在下载测速；其余检测项都是秒级。
会消耗很多流量吗？
测速会下载约 30MB 数据（Cloudflare 20MB + CacheFly 10MB），其余检测项流量可忽略。按量计费的机器请留意。
安装脚本安全吗？
NetPulse 完全开源，安装脚本与源码都可以在 GitHub 上审阅。建议在运行任何远程脚本前先阅读其内容。
检测数据会被上传吗？
检测结果默认只在本地终端显示并保存，不会被收集到任何第三方服务。测试过程中只会访问必要的测速与检测节点。
解锁检测准吗？
状态码只是初步判断（200 ≈ 可访问，403/451 ≈ 疑似区域限制）。Netflix 等建议用专项脚本二次确认，NetPulse 的定位是快速初筛。
如何让 AI Agent 使用 NetPulse？
让 Agent 以非交互方式执行命令并读取 JSON 输出即可，参考上方 Agent 专区的示例，把它封装为一个工具函数。
